A Java parameter taking a `Class<? extends X>` takes a class extending `X`: an SDK class, or an exported Lucent class extending it, whose Java class the OS can make. `new PeriodicWorkRequest.Builder(Refresh, 15n, TimeUnit.MINUTES)` schedules a WorkManager `Worker` written in Lucent. Before, members taking one were left out of the bindings.
