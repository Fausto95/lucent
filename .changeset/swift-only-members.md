Swift-only iOS APIs can be called: initializers, methods, static members, properties (read and written) and top-level functions of Swift types, through a generated `@_cdecl` shim per member the program uses. Swift structs are objects Lucent holds (boxed), changed in place by `mutating` members and setters; enums without payloads are numbers, and enums with payloads are unions discriminated by `kind` (`{ kind: "circle"; center: Point; radius: number } | …`); `throws` becomes a Lucent error; `async` members and getters return promises, and async `@MainActor` members can be awaited from any thread; strings, data, dates, arrays, dictionaries and optionals convert as for Objective-C. Default arguments can be left out, members that protocol extensions give a type are callable (CryptoKit's `SHA256.hash(data:)`, AVFoundation's `load(_:)`), and C structs cross by value. Swift modules on the include paths and Swift-only SDK frameworks (CryptoKit) bind. Generic members get a shim per combination of type arguments the program uses. Protocol values cross as objects, and Lucent classes can implement Swift protocols (method requirements; not protocols with associated types yet).
