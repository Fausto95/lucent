Pin the SDKs and see what an update changes for your code. `lucent sdk lock` records the SDKs and dependencies each module was read from, and every SDK member the code uses, in `lucent-sdk.lock.json`; it needs the SDK of every platform the project has code for, unless `--platforms` leaves one out. `lucent build --frozen` and `lucent check --frozen` then fail when an SDK or dependency differs from the lock, when the code uses a member the lock does not record, or when a platform the lock lists has no SDK installed or would be left to the Gradle build, instead of skipping that platform. `lucent sdk diff` compares the lock with the installed SDKs, member by member, by native identity: removed members, and changed signatures, availability, deprecation and TypeScript names, before you rebuild the app (`--all` adds the members your code does not use). `lucent sdk coverage` now shows how far members get: discovered, representable, generated by the last build, and exercised (from an `--exercised` file), with `--members` for every member's stage and reason. Each build and check writes what it used to `.lucent/sdk-usage.json`.
