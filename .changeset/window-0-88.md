React Native 0.88 and Expo SDK 58 are in the supported window, which is now React Native 0.86 to 0.88 and Expo SDK 57 and 58 (decision 0127). `lucent create` starts bare apps on React Native 0.88.0, from its template (an iOS app that starts in a scene delegate, with Lucent's forwards in it), and Expo apps on SDK 58. `lucent doctor` and `lucent init` count React Native 0.85 and Expo SDK 56 as older than Lucent supports, and React Native 0.89 and Expo SDK 59 as its prerelease lane.
