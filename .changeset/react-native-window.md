Support React Native 0.85 to 0.87 and Expo SDK 56 and 57, the current and the previous stable releases, beside the React Native 0.88 release candidate and the Expo SDK 58 preview. `lucent doctor` names the lane an app's release is on (the stable window or the prerelease lane), fails a release older than the window and warns of a newer one; `lucent init` says when an app's release is outside it.
