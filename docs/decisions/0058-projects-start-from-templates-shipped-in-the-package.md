# 0058. Projects start from templates shipped in the package

- **Date:** 2026-10-08
- **Status:** accepted

`lucent create <name> --template expo|bare|view|library|module` writes a project and sets it up as `lucent init --yes` does; `lucent new module --template function|async|events|view|sdk-ios-android` adds a starter module. The bare template's native projects are React Native's community template (MIT), vendored in `packages/lucent/templates/bare`; the rest is generated by `src/cli/templates/`. _Why:_ starting meant creating an app another way and then running `lucent init`. Downloading templates was rejected so that creating needs no network beyond the package install, and a template can't drift from the Lucent that writes it. A separate `create-lucent` package was left for later: `npx @lucent-lang/lucent create` needs none. _Changed:_ every template is built for the host and checked in `create.test.ts`; the pinned React Native and Expo versions move with the example apps'.
