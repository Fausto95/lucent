Save the module as `src/trip.lucent.ts`. `Fix` is an object type. When JavaScript passes a fix, Lucent checks each field is a number, then copies the fix into a C++ struct.

`radians` and `EARTH_RADIUS_M` aren't exported, so JavaScript never sees them. Only `distance` and `speed` cross the boundary.

## Run it

Build and run the app as in [Your first module](/docs/first-module/#run-the-app). The screen shows `3.16 km at 1.3 m/s`: the walk from the Eiffel Tower to the Louvre, measured in C++.
