## Android

There's nothing to add to the manifest. The SDK marks `requestLocationUpdates` with the location permissions it needs, and `lucent build` adds them to the native package's manifest, which Android merges into the app's.

Asking at run time is still up to the app: `App.tsx` does it with `PermissionsAndroid`, before `watch`.

## Run it

Rebuild the app, since `Info.plist` changed. It asks for the location, then tracks the trip.
