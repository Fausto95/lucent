What a Lucent package's platform code needs from the app that installs it, next to the package's package.json. The app's build merges every package's needs into .lucent/native/resolved.json, naming the package each came from. Needs that cannot all hold fail the build, naming both packages.

```json title="lucent.json"
{
  "ios": {
    "pods": { "LucentAuthKit": "~> 1.0" },
    "frameworks": ["LocalAuthentication"],
    "infoPlist": { "NSFaceIDUsageDescription": "Unlock with Face ID" }
  },
  "android": {
    "dependencies": { "androidx.biometric:biometric": "1.1.0" },
    "permissions": ["android.permission.USE_BIOMETRIC"]
  }
}
```

## The app's own lucent.json

An app's root can have a `lucent.json` too, with the same fields, for its own modules' needs. The build merges it with the packages', and names the app by its package.json's name.

Where the app gives a value of its own, the app's wins. That holds for an `Info.plist` key or entitlement, a manifest component and the main Activity's launch mode. It holds for a pod's or Gradle artifact's version and a Gradle plugin's artifact, while an array joins the packages' values.

Its `launch` and its components' `class` name the app's modules as they are named, without a package. The pods and Gradle dependencies it lists can be imported from `lucent:ios/*` and `lucent:android/*`, as an app's own can.

## Options the app sets

A package can leave a value to the app, such as an API key or a usage string. Its `options` declares each one, with what it means and, when there is one, a default. `{{name}}` in an `Info.plist` value, an entitlement or a manifest component's field is the option's value.

```json title="lucent.json"
{
  "options": {
    "apiKey": { "description": "the Maps API key" },
    "usage": { "description": "why the app uses location", "default": "Show where you are" }
  },
  "ios": {
    "infoPlist": {
      "GMSApiKey": "{{apiKey}}",
      "NSLocationWhenInUseUsageDescription": "{{usage}}"
    }
  }
}
```

The app's own `lucent.json` sets them under `packages`, by package. An option without a default that the app doesn't set fails the build, which says how to set it.

```json title="lucent.json"
{
  "packages": {
    "lucent-maps": { "apiKey": "AIza…" }
  }
}
```
