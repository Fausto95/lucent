---
title: What is Lucent?
description: "Lucent compiles TypeScript modules to C++ that your React Native app calls over JSI, and those modules call iOS and Android APIs directly."
kind: start
---

Lucent is a compiler for React Native's native modules. You write a module in TypeScript, as a `*.lucent.ts` file, and Lucent compiles it to C++ that your app links. JavaScript imports the module like any other file, and each call reaches the C++ over JSI.

<Tabs>
<TabItem label="module">

```ts title="cart.lucent.ts" cpp
export type Item = { price: number; quantity: number };

export function total(items: Item[], taxRate: number): number {
  let sum = 0;
  for (const item of items) {
    sum += item.price * item.quantity;
  }
  return Math.round(sum * (1 + taxRate) * 100) / 100;
}
```

</TabItem>
<TabItem label="JS usage">

```tsx title="App.tsx"
import { total } from "./src/cart.lucent";

total([{ price: 4.5, quantity: 2 }, { price: 3, quantity: 1 }], 0.2); // 14.4
```

</TabItem>
</Tabs>

The import is typed from the module's source. No JavaScript engine runs the module: the array is [checked and copied](/docs/api/language/boundary/) into C++ values, and the loop runs as C++. A module is written in a subset of TypeScript, without `any` or `eval` ([why](/docs/api/language/#why-a-subset)).

## Call iOS and Android


</TabItem>
<TabItem label="JS usage">

```tsx title="App.tsx"
import { hasStringAsync } from "./src/clipboard.lucent";

hasStringAsync().then((hasText) => console.log(hasText)); // true when the clipboard holds text
```

</TabItem>

A module imports the iOS and Android SDKs directly, typed from your Xcode and Android SDK, with no Swift or Kotlin to write. Each platform's build compiles its own side of the `PLATFORM` test.

## When to use it

- Logic you want as native code: parsers, codecs, geometry, data structures.
- Calls to iOS and Android APIs, written once in TypeScript.
- Work that must stay off the JS thread: an `async` export runs on a background thread.

Lucent is experimental, not for production apps, and has [known limitations](/docs/releases/roadmap/#known-limitations). [The comparison](/docs/guides/comparison/) sets it beside Expo Modules, Nitro and Turbo Native Modules.
