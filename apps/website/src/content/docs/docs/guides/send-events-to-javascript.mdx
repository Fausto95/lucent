<Tabs>
<TabItem label="module">

```ts title="downloads.lucent.ts"
import { delay, subscribe } from "lucent:core";

export type Progress = { url: string; percent: number };

const listeners = new Map<number, (progress: Progress) => void>();
let nextId = 0;

export async function download(url: string): Promise<void> {
  for (let percent = 0; percent <= 100; percent += 10) {
    for (const listener of listeners.values()) listener({ url, percent });
    await delay(200); // stand-in for the network
  }
}

/** Sends every download's progress to `onProgress`, until `signal` aborts. */
export async function watchDownloads(
  onProgress: (progress: Progress) => void,
  signal: AbortSignal,
): Promise<void> {
  await subscribe<Progress>(
    (next) => {
      const id = nextId++;
      listeners.set(id, next);
      return () => {
        listeners.delete(id);
      };
    },
    onProgress,
    signal,
  );
}
```

<TabItem label="JS usage">

```tsx title="App.tsx"
import { useEffect, useState } from "react";
import { Button, Text, View } from "react-native";
import { type Progress, download, watchDownloads } from "./src/downloads.lucent";

export default function App() {
  const [progress, setProgress] = useState<Progress>();

  useEffect(() => {
    const controller = new AbortController();
    watchDownloads(setProgress, controller.signal).catch(console.error);
    return () => controller.abort();
  }, []);

  return (
    <View>
      <Button title="Download" onPress={() => download("https://example.com/a.zip")} />
      <Text>{progress ? `${progress.url}: ${progress.percent}%` : "Idle"}</Text>
    </View>
  );
}
```

`subscribe(register, onValue, signal)` calls `register` at once, with `next`, `end` and `fail`. Here it adds `next` to the listeners, and returns the cleanup that removes it. Each `next(value)` passes the value to `onValue` while the subscription is open.

The signal aborting, `end()` or `fail(error)` ends the subscription, and its cleanup then runs once. The promise resolves on `end()` and on the signal, and rejects on `fail(error)`.

- When the component unmounts, `abort()` ends the subscription, and `watchDownloads` resolves.
- Each value reaches JavaScript as a copy, posted to the JS thread. So `onProgress` returns `void`, and what it throws is only logged ([Call a JavaScript callback](/docs/guides/accept-a-js-callback/)).
- A JavaScript reload doesn't end a subscription that module code made. End each one from JavaScript, as the effect's cleanup does ([What a reload does](/docs/api/language/modules/#what-a-reload-does)).

The full contract is on [lucent:core](/docs/api/lucent-core/#subscribe). For events from an SDK listener, `register` adds the listener and the cleanup removes it: see [Implement an SDK delegate or listener](/docs/guides/implement-a-delegate/). For one value rather than a stream, [Turn a callback API into a promise](/docs/guides/await-a-callback-api/).
