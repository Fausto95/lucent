```ts title="uploads.lucent.ts"
import { delay } from "lucent:core";

export type Photo = { name: string; size: number };

/** Synchronous: `keep` runs at once, and what it returns is checked. */
export function pick(photos: Photo[], keep: (photo: Photo) => boolean): Photo[] {
  return photos.filter(keep);
}

/** Async: each call to `confirm` and `onProgress` is posted to the JS thread. */
export async function upload(
  photos: Photo[],
  confirm: (photo: Photo) => Promise<boolean>,
  onProgress: (sent: number) => void,
): Promise<number> {
  let sent = 0;
  for (const photo of photos) {
    if (!(await confirm(photo))) continue;
    await delay(photo.size / 10_000); // stand-in for the network
    onProgress(++sent);
  }
  return sent;
}
```

<TabItem label="JS usage">

```tsx title="App.tsx"
import { useState } from "react";
import { Alert, Button, Text, View } from "react-native";
import { type Photo, pick, upload } from "./src/uploads.lucent";

const photos: Photo[] = [
  { name: "beach.jpg", size: 2_400_000 },
  { name: "icon.png", size: 12_000 },
];

function ask(photo: Photo): Promise<boolean> {
  return new Promise((resolve) =>
    Alert.alert(`Upload ${photo.name}?`, undefined, [
      { text: "Skip", onPress: () => resolve(false) },
      { text: "Upload", onPress: () => resolve(true) },
    ]),
  );
}

export default function App() {
  const [sent, setSent] = useState(0);
  const start = () => upload(pick(photos, (photo) => photo.size > 100_000), ask, setSent);

  return (
    <View>
      <Button title="Upload large photos" onPress={start} />
      <Text>{sent} sent</Text>
    </View>
  );
}
```

`pick` is synchronous: it runs on the JS thread, so it calls `keep` at once and waits for its result. `keep` may return any value that crosses, checked like an argument. What it throws is a Lucent error that `catch` handles.

`upload` is async, so its code runs off the JS thread. Each callback call is posted to the JS thread, and the callback must return `void` or a `Promise`:

- `onProgress` returns `void`, so nothing comes back and `upload` goes on at once. What it throws is only logged, as `Uncaught error in callback: …` ([Read errors and logs](/docs/guides/read-errors-and-logs/)).
- `confirm` returns a `Promise`, which `upload` awaits. A throw or a rejection in `confirm` rejects that `await`.
- A callback declared to return anything else throws an `Error` when async code calls it. Make it return a `Promise`.

## Keep a callback for later

Lucent keeps a callback alive while it holds a reference to it. Stored in module state, the function stays alive with what it captures, until you remove it ([Listeners and subscriptions](/docs/api/language/memory/#listeners-and-subscriptions)). To send a stream of values, use the pattern in [Stream events to JavaScript](/docs/guides/send-events-to-javascript/).

The full rules are in [Callbacks](/docs/api/language/boundary/#callbacks).
