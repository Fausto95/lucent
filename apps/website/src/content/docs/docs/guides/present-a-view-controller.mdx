<TabItem label="share.lucent.ts">

```ts title="share.lucent.ts"
import { PLATFORM } from "lucent:platform";
import { UIActivityViewController } from "lucent:ios/UIKit";
import { present } from "lucent:ios";
import { error } from "lucent:core";

/** Shows the share sheet, and resolves with whether the person shared. */
export async function share(text: string, signal?: AbortSignal): Promise<boolean> {
  if (PLATFORM !== "ios") throw error("E_UNSUPPORTED", "Sharing is iOS only");

  return present<boolean>((resolve) => {
    const sheet = new UIActivityViewController([text], null);
    sheet.completionHandler = (_type, completed) => resolve(completed);
    return sheet;
  }, signal);
}
```

<TabItem label="App.tsx">

```tsx title="App.tsx"
import { Button, Platform } from "react-native";
import { share } from "./src/share.lucent";

export default function App() {
  const onPress = async () => {
    try {
      const shared = await share("Made with Lucent");
      console.log(shared ? "shared" : "closed");
    } catch (e) {
      if ((e as Error).name !== "AbortError") throw e;
      console.log("dismissed");
    }
  };

  return Platform.OS === "ios" ? <Button title="Share" onPress={onPress} /> : null;
}
```

`present()` runs your function on the main thread, so UIKit calls compile there without `main()`. Make the view controller, connect its completion handler or delegate to `resolve` or `reject`, and return it. Lucent presents it from the scene the person is using, above what that scene already shows.

The promise settles once, and settling dismisses the view controller, so you don't call `dismiss`. The person swiping a sheet away rejects it with an `AbortError`, unless its handler settles it first. With `present<void>`, `resolve` takes no value.

On iPad, a popover with no anchor, such as the share sheet, is anchored to the middle of the presenting view. [lucent:ios](/docs/api/lucent-ios/#present) has the rest.

## Present your own screen

A Lucent class that extends `UIViewController` is presented the same way. Make it in the function, and give it `resolve` to call when the person is done. [Subclass an SDK class](/docs/guides/subclass-an-sdk-class/) shows the overrides.
