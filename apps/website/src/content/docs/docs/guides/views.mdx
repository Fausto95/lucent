<Steps>

1. ### Write a component

   <Tabs>
   <TabItem label="greeting.lucent.tsx">

   ```tsx title="greeting.lucent.tsx"
   import { appContext } from "lucent:android";
   import { TextView } from "lucent:android/android.widget";
   import { UILabel } from "lucent:ios/UIKit";
   import { PLATFORM } from "lucent:platform";
   import { effect } from "lucent:ui";

   export function Greeting(props: { name: string }) {
     if (PLATFORM === "ios") {
       const label = new UILabel();

       effect(() => {
         label.text = `Hello, ${props.name}`;
       });

       return label;
     }

     const text = new TextView(appContext());

     effect(() => text.setText(`Hello, ${props.name}`));

     return text;
   }
   ```

   </TabItem>
   <TabItem label="App.tsx">

   ```tsx title="App.tsx"
   import { View } from "react-native";
   import * as greeting from "./greeting.lucent";

   const { Greeting } = greeting as unknown as typeof import("./.lucent/native/types/views/greeting");

   export default function App() {
     return (
       <View style={{ padding: 48 }}>
         <Greeting name="Ada" />
       </View>
     );
   }
   ```

   </TabItem>
   </Tabs>

   An exported function that returns a view is a component. Its body, the setup, runs once each time React mounts it, and the effect sets the text again when `name` changes.

   `lucent build` writes the component's React type to `.lucent/native/types/views/greeting.d.ts`. Nothing connects that file to your app's TypeScript yet, so App.tsx casts the import to it.

   To start from platform files instead, `npx lucent new view Card` writes `src/card.lucent.ts` and an iOS and an Android `.lucent.tsx`, each a label in a [Flex](/docs/api/views/platform-views/#layout).

2. ### Build and run the app

   <Tabs syncKey="setup">
   <TabItem label="Expo">

   ```sh title="terminal"
   npx expo prebuild
   npx expo run:ios
   ```

   </TabItem>
   <TabItem label="Bare React Native">

   ```sh title="terminal"
   npx lucent build
   cd ios && pod install && cd ..
   npx react-native run-ios
   ```

   </TabItem>
   </Tabs>

   A component adds native code, so `lucent build` asks for a new build of the app:

   ```sh title="terminal" nocopy
   modules  greeting  ios android
   next     rebuild the app (iOS: pod install first)
   actions  reinstall the app           android       android/src/main/AndroidManifest.xml
            relink native dependencies  ios, android  LucentNative.podspec, android/consumer-rules.pro +124 more
            recompile native code       ios, android  android/src/main/java/dev/lucent/LucentViewManagers.java, android/src/main/java/dev/lucent/generated/LucentGreeting_b616637901d4Manager.java +133 more
            reload JavaScript           ios, android  js/_lucent/runtime.js, js/_lucent/views.js +1 more
   ```

   When you save a component later, Metro prints the same request on one line. [Get a module change into the running app](/docs/guides/apply-a-change/) explains each action.

</Steps>
