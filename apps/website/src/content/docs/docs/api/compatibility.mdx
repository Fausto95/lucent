:::note
No stable release meets these yet. In October 2026, `react-native@latest` is 0.87 and `expo@latest` is SDK 57. Use the React Native 0.88 release candidate (`react-native@next`) or the Expo SDK 58 preview (`expo@next`), as the example apps do.
:::

|  | Supported |
| --- | --- |
| React Native | 0\.88 or later, New Architecture |
| Expo | SDK 58 or later, in a development build |
| Node | 22\.12 or later |
| JDK, for Android builds | 17 to 21 |
| Android | API 24 and later; newer APIs need an `available` check |
| iOS | 15\.1 and later; APIs newer than the app's deployment target need an `available` check |
| TypeScript | 5\.9.3, which the package brings; modules are checked against `es2022` and `esnext.disposable` |
| Xcode, Android SDK and NDK | the versions your React Native version needs |

## Operating systems

| Machine | What works |
| --- | --- |
| macOS | Everything: iOS and Android builds, and checks of both platforms' code. |
| Linux | Android builds and checks. Without Xcode, iOS code is untyped: `lucent build` and `lucent check` skip iOS with a warning. |
| Windows | Untested. WSL is a Linux machine. |

`lucent doctor` checks these on your machine, and this table is generated from the same numbers.

Tested on the iOS simulator (Xcode 27) and the Android emulator, in the example apps, bare and Expo. Not yet on physical devices ([roadmap](/docs/releases/roadmap/)).
