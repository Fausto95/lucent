## PLATFORM

```ts title="platform.d.ts"
const PLATFORM: "ios" | "android";
```

The platform: `if (PLATFORM === "ios") { … } else { … }` and `PLATFORM === "ios" ? … : …` compile each platform's branch only, so a shared module can use `lucent:ios/…` and `lucent:android/…` in them.
