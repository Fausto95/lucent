The global variables `console`, `AbortController`, `AbortSignal`, `TextEncoder`, `TextDecoder`, `URL`, `URLSearchParams` and `crypto`, the timer functions `setTimeout`, `setInterval` and `queueMicrotask`, and `atob` and `btoa`, have these types. The JavaScript built-ins a module can use are on [Built-ins](/docs/api/language/built-ins/).

## Types

### Console

```ts title="globals.d.ts"
interface Console {
  log(...data: unknown[]): void;
  info(...data: unknown[]): void;
  debug(...data: unknown[]): void;
  warn(...data: unknown[]): void;
  error(...data: unknown[]): void;
}
```

What `console` logs. On iOS each line goes to the unified log, prefixed `[Lucent]`; on Android, to logcat under the tag `Lucent`. An object prints as `String(obj)`.

### AbortSignal

```ts title="globals.d.ts"
interface AbortSignal {
  readonly aborted: boolean;
  readonly reason: any;
  throwIfAborted(): void;

}
```

The signal of an `AbortController`, which JavaScript passes to cancel an async call. Lucent code checks it, waits on it, or passes it on.

| Member | What it does |
| --- | --- |
| `readonly aborted: boolean;` |  |
| `readonly reason: any;` | Not available in Lucent code: catch the error from throwIfAborted() or delay() instead. |
| `throwIfAborted(): void;` |  |
| `addEventListener(type: "abort", listener: () => void): void;` |  |

### Crypto

```ts title="globals.d.ts"
interface Crypto {
  getRandomValues<T extends ArrayBufferView | null>(array: T): T;
  randomUUID(): `${string}-${string}-${string}-${string}-${string}`;
}
```

The platform's secure random generator (`arc4random_buf` on iOS, `getrandom` on Android). `subtle` is not available in Lucent code.

| Member | What it does |
| --- | --- |
| `getRandomValues<T extends ArrayBufferView \| null>(array: T): T;` | Fills an array of integers with random values, at most 65536 bytes, and returns it. |
| `randomUUID(): `$\{string\}-$\{string\}-$\{string\}-$\{string\}-$\{string\}`;` | A random version 4 UUID, in lowercase. |

### TextEncoder

```ts title="globals.d.ts"
interface TextEncoder {
  readonly encoding: string;
  encode(input?: string): Uint8Array<ArrayBuffer>;
  encodeInto(source: string, destination: Uint8Array): TextEncoderEncodeIntoResult;
}
```

Encodes strings as UTF-8, a lone surrogate as U+FFFD.

| Member | What it does |
| --- | --- |
| `readonly encoding: string;` | Always "utf-8". |
| `encode(input?: string): Uint8Array<ArrayBuffer>;` |  |
| `encodeInto(source: string, destination: Uint8Array): TextEncoderEncodeIntoResult;` | Writes the whole characters of `source` that fit in `destination`, from its start. |

### TextDecoderOptions

```ts title="globals.d.ts"
interface TextDecoderOptions {
  fatal?: boolean;
  ignoreBOM?: boolean;
}
```

`fatal`: throw a TypeError on bytes that are not UTF-8, rather than decode them as U+FFFD. `ignoreBOM`: keep a leading byte order mark.

### TextDecodeOptions

```ts title="globals.d.ts"
interface TextDecodeOptions {
```

`stream`: more input follows, so a character the input ends inside of waits for it.

### URL

```ts title="globals.d.ts"
interface URL {
  hash: string;
  host: string;
  hostname: string;
  href: string;
  toString(): string;
  readonly origin: string;
  password: string;
  pathname: string;
  port: string;
  protocol: string;
  search: string;
  readonly searchParams: URLSearchParams;
  username: string;
  toJSON(): string;
}
```

A URL, parsed as the URL standard says (by Ada, the parser Node uses). Each part reads and writes as a string; `searchParams` is the same object each time, and a change to either shows in the other.
