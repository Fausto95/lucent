The global variables `console`, `AbortController` and `AbortSignal` have these types. The JavaScript built-ins a module can use are on [Built-ins](/docs/api/language/built-ins/).

## Types

### Console

```ts title="globals.d.ts"
interface Console {
  log(...data: unknown[]): void;
  info(...data: unknown[]): void;
  debug(...data: unknown[]): void;
  warn(...data: unknown[]): void;
  error(...data: unknown[]): void;
}
```

What `console` logs. On iOS each line goes to the unified log, prefixed `[Lucent]`; on Android, to logcat under the tag `Lucent`. An object prints as `String(obj)`.

### AbortSignal

```ts title="globals.d.ts"
interface AbortSignal {
  readonly aborted: boolean;
  readonly reason: any;
  throwIfAborted(): void;
  addEventListener(type: "abort", listener: () => void): void;
}
```

The signal of an `AbortController`, which JavaScript passes to cancel an async call. Lucent code checks it, waits on it, or passes it on.

| Member | What it does |
| --- | --- |
| `readonly aborted: boolean;` |  |
| `readonly reason: any;` | Not available in Lucent code: catch the error from throwIfAborted() or delay() instead. |
| `throwIfAborted(): void;` |  |
| `addEventListener(type: "abort", listener: () => void): void;` |  |

### AbortController

```ts title="globals.d.ts"
interface AbortController {
  readonly signal: AbortSignal;
  abort(reason?: any): void;
}
```

Makes a signal, and aborts it.

| Member | What it does |
| --- | --- |
| `readonly signal: AbortSignal;` |  |
| `abort(reason?: any): void;` | In Lucent code, `reason` must be an Error. |
