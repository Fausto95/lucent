## Functions

### effect()

```ts title="ui.d.ts"
function effect(run: () => void): void;
```

Runs `run` now, and again after a prop or signal it read changes. Before it runs again, and when the view goes, what it registered with `onDispose` runs.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `run` | `() => void` | yes | Reads props and signals; runs again when one of them changes. |

### signal()


A signal holding `initial`, for this mount of the view.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `initial` | `T` | yes | Its first value. |

### expose()

```ts title="ui.d.ts"
function expose<T extends object>(commands: T): void;
```

Gives the component's React ref `commands`: called once, at the top of setup or of a PLATFORM branch there, with an object literal of functions. A command returning nothing runs on the main thread; one returning a value (or a promise) answers JavaScript's promise.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `commands` | `T` | yes | An object literal of functions. |

### onDispose()

```ts title="ui.d.ts"

```

Runs `cleanup` when the view goes; inside an effect, before the effect runs again.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `cleanup` | `() => void` | yes | What to undo. |

### slot()

```ts title="ui.d.ts"
function slot<T extends object>(): T;
```

The view a component's React children are mounted in, for a component whose props declare `children: Children`. Call it once, in a `const` at the top of setup, with the platform's container class: `slot<UIView>()` on iOS, `slot<ViewGroup>()` on Android.

Put it in the view setup returns, where the children belong: it fills the view it is added to unless setup sizes it. React lays the children out in the component's own coordinates, wherever the slot is, and they show within the slot's bounds. React Native adds, moves and removes them: setup never changes the slot's subviews.

### invalidateSize()

```ts title="ui.d.ts"
function invalidateSize(): void;
```

Has the view measured again once the main thread's work ends, after a change to its native content that its host can't hear of. The host hears of every function setup makes running: an effect, a native callback, a command. Code after an `await` runs in none of them.

## Classes

### Flex

```ts title="ui.d.ts"
class Flex {
  constructor(none: never);
  "~jsx"?: {
    style?: LayoutStyle;
    children?: FlexChild | readonly (FlexChild | readonly FlexChild[])[];
  };
}
```

A container of native views laid out by React Native's Yoga: its `style` places its children, and each child's `layout` places it. It writes its children's frames, and nothing else does; a native container among them (a stack view, a LinearLayout) lays out its own. Native view JSX only: `<Flex style={{ flexDirection: "row", gap: 8 }}>…</Flex>`.

| Member | What it does |
| --- | --- |
| `constructor(none: never);` | Made by its JSX only: nothing can be passed. |

## Types

### Signal

```ts title="ui.d.ts"
interface Signal<T> {
  get(): T;
  peek(): T;
  set(value: T): void;
}
```

A value of the view's own, which effects track like props.

| Member | What it does |
| --- | --- |
| `get(): T;` | The value; inside an effect, the effect runs again when it changes. |
| `peek(): T;` | The value, without tracking it. |
| `set(value: T): void;` | Changes it, unless `value` is the same (Object.is), running what read it. |

### Bound

```ts title="ui.d.ts"
interface Bound<T> {
}
```

A signal given to a view of a toolkit body that changes it: SwiftUI's Binding, or Compose's value and its change callback. The view shows the signal's value, and a change the user makes sets the signal. The signal may keep another value, and the view shows what it keeps.

### ClosedRange

```ts title="ui.d.ts"
interface ClosedRange<T> {
}
```

The numbers from `from` to `to`, both included, given to a view of a toolkit body that takes a range (a slider's, a stepper's bounds): SwiftUI's `from ... to`. Written where the view takes it, as bind(signal) is.

### Children

```ts title="ui.d.ts"
interface Children {
}
```

The type of a component's `children` prop: the React elements JavaScript nests in it, which React Native mounts in the view `slot` gives setup. Setup never reads them.

### LayoutLength

```ts title="ui.d.ts"
type LayoutLength = number | `${number}%`;
```

A length in points on iOS and dp on Android, or a percent of the parent's (`"50%"`).

### LayoutDimension

### NativeViewTag

```ts title="ui.d.ts"
type NativeViewTag<V> = abstract new (...args: never[]) => V;
```

A native view class, as a JSX tag: any class whose instances are `V`.

### NativeAttributes

```ts title="ui.d.ts"
type NativeAttributes<T> = [
  {
    [K in keyof T]-?: K extends `~jsx:${string}` ? (x: NonNullable<T[K]>) => void : never;
  }[keyof T],
] extends [never]
  ? {}
  : {
        [K in keyof T]-?: K extends `~jsx:${string}` ? (x: NonNullable<T[K]>) => void : never;
      }[keyof T] extends (x: infer I) => void
    ? I
    : never;
```

The JSX attributes of a native view class: what each class in its hierarchy gives under its own `~jsx:<module>.<class>` key, together. The keys are derived by rule from the declarations. Each key's type takes the class itself (`this`), so a control event's handler gets the tag's class.

### Continuous

```ts title="ui.d.ts"
type Continuous<F extends (...args: never[]) => void> = F;
```

Marks an event prop's callback type: JavaScript hears each of its events at a lower priority than a discrete one (a tap). React may then batch what they update. It suits events that come often, such as a drag or a timer, while an unmarked event is discrete.

### Coalesced

```ts title="ui.d.ts"
type Coalesced<F extends (...args: never[]) => void> = F;
```

Marks an event prop's callback type as continuous, and coalesced. While the view's latest event waiting for JavaScript is one of this type, a new one replaces it, so JavaScript hears the latest value. It suits events whose latest value is all that counts, such as a scroll position.
