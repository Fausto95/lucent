|  | Supported |
| --- | --- |
| React Native | 0\.88 or later, New Architecture |
| Expo | SDK 58 or later, in a development build |
| Node | 22\.12 or later |
| JDK, for Android builds | 17 to 21 |
| Android | API 24 and later; newer APIs need an `available` check |
| iOS | 15\.1 and later; newer APIs need an `available` check |
| TypeScript | 5\.9.3, which the package brings; modules are checked against `es2022` and `esnext.disposable` |
| Xcode, Android SDK and NDK | the versions your React Native version needs |

`lucent doctor` checks these on your machine, and this table is generated from the same numbers.

Tested on the iOS simulator (Xcode 27) and the Android emulator, in the example apps, bare and Expo. Not yet on physical devices ([roadmap](/docs/releases/roadmap/)).
