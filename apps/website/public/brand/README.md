# Brand assets

`lucent-mark.svg` is the Lucent project mark.

Integration logos are sourced from their respective projects:

- [React Native](https://github.com/facebook/react-native-website/blob/main/website/static/img/header_logo.svg): original atom logo, with a responsive viewBox.
- [Expo](https://github.com/expo/expo/blob/main/docs/public/static/images/expo-logo.svg): symbol extracted from the official wordmark, displayed in off-white for the dark background.
- [Nitro](https://github.com/mrousavy/nitro/blob/main/docs/static/img/android-chrome-192x192.png): original nitrous bottle icon.

These marks belong to their respective owners and identify supported integrations.
